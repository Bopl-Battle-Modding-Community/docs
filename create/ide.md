# Choosing an IDE
In order to work with Bopl Battle's code, you need to install an integrated development environment (IDE) for .NET. There are many out there, but the main three IDEs are typically:
- [Visual Studio](https://visualstudio.microsoft.com/)
- [Visual Studio Code](https://code.visualstudio.com/)
- [JetBrains Rider](https://www.jetbrains.com/rider/)

Not sure which one to choose? Use this table to help you:
|                    | Linux Support | Full C# Suite | Usage                      |
|--------------------|:-------------:|:-------------:|:--------------------------:|
| Visual Studio      | ❌            | ✅            | Non-commerical (Community) |
| Visual Studio Code | ✅            | ❌            | Private and commercial     |
| JetBrains Rider    | ✅            | ✅            | Non-commerical (Community) |
