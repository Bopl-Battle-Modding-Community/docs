# Quickstart
These guides will walk you through the basics of making Bopl Battle mods, allowing you to get started easily and make your own mod for Bopl Battle.

::: warning
It is **highly recommended** that you have a solid understanding of the [.NET ecosystem](https://dotnet.microsoft.com/en-us/) (C#, MSBuild, NuGet, etc.) and the [Unity game engine](https://unity.com/) before creating a mod.

It is also recommended that you have a basic understanding of the [command line interface](https://en.wikipedia.org/wiki/Command-line_interface) (CLI) for your operating system. **You will be required to use the CLI at many points throughout these guides**.

In addition, **avoid heavily relying on generative AI for creating Bopl Battle mods**. Most, if not all, LLMs (even higher-end models) cannot legally access Bopl Battle's source code and may end up hallucinating nonexistent classes, methods, or properties. <!-- also make it yourself stop being lazy -->
:::

Before you begin, it is recommended to have the following on your computer:
- An up-to-date version of your operating system (Windows works best, but you can also use Linux if you prefer)
- The latest stable version of [Git](https://git-scm.com/) (needed for version control)
- [Bopl Battle](https://store.steampowered.com/app/1686940/Bopl_Battle/) (obviously)

Once everything is set up, continue to the next page to finish setup.
