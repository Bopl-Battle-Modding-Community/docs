# Thunderstore Packager
This tool allows you to package your mod for upload to Thunderstore.

::: info

All processing is done locally. Nothing you put here gets uploaded to a server (except, of course, Thunderstore's servers).

:::

Red asterisks (*) indicate a field is required.

<script setup lang="ts">
import ThunderstorePackager from './ThunderstorePackager.vue';
</script>

<ThunderstorePackager />

Once you're done packaging your mod, learn how to [upload it to Thunderstore](/create/thunderstore).
