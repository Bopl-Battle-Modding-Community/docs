# Install a mod manager
In order to easily play Bopl Battle with mods, you need to install a mod manager. Mod managers easily handle all the required files and allow you to use more features, like custom profiles, mod list sharing, simple configuration editors, and more.

## What one should I use?
The most popular mod managers available are:
- [Gale](https://github.com/Kesomannen/gale) (developed independently from Thunderstore)
- [r2modman](https://r2modman.com/download-latest/) (initially made for Risk of Rain 2, but now supports all Thunderstore games)
- [Thunderstore Mod Manager](https://www.overwolf.com/app/thunderstore-thunderstore_mod_manager) (the official Thunderstore mod manager, based on r2modman)
