# r2modman
r2modman is the original Thunderstore mod manager. It supports almost all Thunderstore games and is very feature-complete, although its resource footprint is a lot heavier compared to Gale. 

## Screenshot
![Screenshot of r2modman when opened](/images/screenshots/installing/r2modman.png)

## Pros
- Developed alongside Thunderstore (more game support)
- Profiles and code exports
- Larger userbase (easier to fix issues)

## Cons
- Electron runtime (slower and more resource intensive)
- Limited customization

## Installation
[Download the latest version](https://github.com/ebkr/r2modmanPlus/releases/latest) of r2modman for your operating system.
